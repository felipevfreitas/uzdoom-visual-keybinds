VISUAL KEYBINDS 1.0.0 - on-screen keyboard for your UZDoom key bindings
=====================================================================

Requires UZDoom 5.0 or newer. Works on its own or together with
Tabbed Options (it shows at the top of the Controls tab).

Where to find it
----------------
Options > Controls > "Visual keyboard" (first entry).
From the console: openmenu VKB_KeyboardMenu

Keyboard screen
---------------
Shows the keyboard and the mouse buttons, colored by what they do:
  Green  - the key runs an action
  Amber  - custom command (typed in the console or added by a mod)
  Red    - several actions on the same key (e.g. "+attack; +use")
  Gray   - free

Each key shows its action at the bottom. Hover a key (or use the arrow
keys) to see what it does in Game, Double tap and Automap.

At the top: keyboard size (100%, 75%, 60%) and which binding set to show
(Game, Double tap, Automap).

  Arrows / d-pad      move between keys
  Enter / click       open the key editor
  PgUp / PgDn, LB/RB  switch Game / Double tap / Automap
  Home / End          switch keyboard size

Key editor
----------
Tabs "On this key" and "All actions" (with search: just start typing).
Pick an action, then:
  Assign here       put the action on this key
  Press a key...    put the action on the next key/button you press
  Unbind            remove the action from every key
  Default           give only this action its default keys back
  Clear key         leave this key free

  Up / Down                        choose an action
  Left / Right, Tab, LB / RB       switch tab
  Enter                            Assign here
  Del                              Unbind
  Backspace                        delete a search character

Changes apply right away, like in the stock controls menu.

Mod actions
-----------
The list includes the actions from the game's controls menus and the
ones mods add in their own menus inside Options.
